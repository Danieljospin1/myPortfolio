# Jospin Portfolio

Portfolio website for BISUBIZO Daniel Jospin.

## Stack

- React
- TypeScript
- Vite
- Framer Motion
- Lucide React
- Plain CSS for the first implementation

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Before publishing

Replace the placeholder GitHub, LinkedIn, and email links in `src/App.tsx`.
